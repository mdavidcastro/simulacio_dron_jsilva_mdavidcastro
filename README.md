# SimDron

## Descripción

**SimDron** es un simulador de drones web desarrollado para representar y analizar el comportamiento de un dron dentro de un entorno controlado.

El proyecto combina **Python, Flask y JavaScript** para construir una aplicación capaz de procesar la dinámica del dron, ejecutar simulaciones y visualizar los resultados de forma interactiva.

Para el cálculo y la aproximación numérica del movimiento se implementó el **método de Runge-Kutta**, permitiendo obtener una simulación más precisa de la evolución del sistema a lo largo del tiempo.

El proyecto integra conceptos de **programación, métodos numéricos, modelado matemático y desarrollo web**, conectando la lógica de simulación desarrollada en Python con una interfaz accesible desde el navegador.

## Tecnologías

| Tecnología | Uso |
|---|---|
| **Python** | Lógica de simulación, modelado matemático y cálculos numéricos |
| **Flask** | Desarrollo del backend y comunicación entre cliente y servidor |
| **JavaScript** | Lógica del frontend, interactividad y manejo dinámico de datos |
| **Runge-Kutta** | Integración numérica para la resolución de las ecuaciones diferenciales del sistema |
| **HTML5** | Estructura y marcado de la interfaz |
| **Tailwind CSS** | Diseño de la interfaz y estilos mediante clases utilitarias |
| **Git / GitHub** | Control de versiones y trabajo colaborativo |
