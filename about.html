Acerca de AeroMundo

Una plataforma de simulación construida sobre análisis matemático y visualización avanzada.

Visión General

AeroMundo combina modelación física, simulación numérica, gráficos 3D y análisis automatizado para estudiar el comportamiento de drones en vuelo. El sistema se divide en dos componentes principales: un entorno visual interactivo en el navegador y un motor de simulación basado en Python, que calcula el movimiento a partir de ecuaciones diferenciales de primer orden.

La interfaz del usuario está construida con un diseño moderno basado en gradientes, transparencias y tipografía clara. Utiliza herramientas como:

  • TailwindCSS para estilos responsivos y animaciones.
  • JavaScript para manejar interacción, validación e interactividad.
  • Un sistema visual que integra pestañas, tarjetas y secciones dinámicas.

Desde esta capa se envían los parámetros seleccionados por el usuario —posición inicial, velocidad, gravedad, viento y resistencia del aire— hacia el motor de simulación. Cuando los resultados regresan, la interfaz se encarga de representarlos en forma de gráficos o escenas 3D.

El motor físico está implementado en Python usando una arquitectura ligera pero robusta. Utiliza:

  • Flask para recibir y devolver datos al navegador.
  • Numpy para cálculos vectoriales y algebra lineal.
  • SQLite para almacenar todas las simulaciones realizadas.
  • Métodos numéricos para resolver ecuaciones diferenciales.

La simulación aplica fuerzas fundamentales: gravedad, viento y resistencia aerodinámica. Estas se combinan siguiendo ecuaciones diferenciales de primer orden que describen la evolución de la velocidad y la posición.

Para resolverlas, utiliza el método de integración Runge–Kutta de cuarto orden (RK4), ampliamente usado en aeronáutica por su precisión y estabilidad.

Los resultados de la simulación son procesados para obtener variables como:

  • Módulo de la posición
  • Módulo de la velocidad
  • Distancia recorrida
  • Aceleraciones aproximadas

Todo esto se representa mediante gráficos generados dinámicamente utilizando bibliotecas especializadas de visualización.

AeroMundo incorpora un entorno de visualización tridimensional donde se muestra la trayectoria simulada del dron. El sistema usa un motor 3D basado en WebGL para construir escenas que incluyen:

  • Grillas tridimensionales
  • Controles orbitales de cámara
  • Modelos 3D de drones
  • Líneas animadas que representan la trayectoria

Esta vista permite analizar el comportamiento espacial del dron, detectar inestabilidades y comprender mejor la física del movimiento.

Cada simulación queda registrada en una base de datos local. El sistema almacena:

  • Condiciones iniciales
  • Parámetros del entorno
  • Datos de trayectoria
  • Fecha y hora

Luego, una interfaz dedicada permite explorar el historial mediante tarjetas interactivas. Cada log puede abrirse en un modal con:

  • Vista 3D
  • Gráficas
  • Evaluaciones de seguridad del vuelo
  • Resumen de comportamiento

Este módulo transforma la simulación en un verdadero laboratorio digital, permitiendo comparar escenarios, estudiar fallos y evaluar riesgos.

Para resolver las ecuaciones diferenciales que describen el movimiento del dron, AeroMundo emplea técnicas numéricas ampliamente utilizadas en simulación, ingeniería y aeronáutica. Estos métodos aproximan soluciones que no pueden calcularse de forma exacta.

Método de Euler

Rápido y simple, útil como referencia, pero poco preciso para dinámicas complejas.

Runge–Kutta (RK2, RK4)

Métodos de alta precisión ideales para simulaciones físicas y sistemas aeroespaciales.

Newton–Raphson

Perfecto para resolver ecuaciones no lineales complejas.

Integración Trapezoidal / Simpson

Usadas para integrar funciones difíciles de evaluar analíticamente.

Jacobi / Gauss–Seidel

Métodos iterativos para resolver sistemas de ecuaciones grandes.

En AeroMundo, el método principal utilizado es Runge–Kutta de 4° orden (RK4), elegido por su equilibrio entre estabilidad, eficiencia y precisión.
